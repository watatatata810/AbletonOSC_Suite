# LTC Sender

Ableton Live のクリップとして鳴らす LTC (音声のタイムコード) を、作成・検査・監視し、シーンを途中から揃えて再生するツールです。設計は [docs/261028-2253_ltc-sender-design.md](../../docs/261028-2253_ltc-sender-design.md) を参照してください。

## 仕組み

- LTC は**音声ファイル**として、BGM と同じシーンの LTC トラックに置き、BGM と一緒に発音します (Live 内でサンプル単位で揃います)
- このツールは Live のプロジェクトを書き換えません。発音・スクラブ・再生位置の移動だけを送ります

## 導入 (初回と、AbletonOSC を更新した時)

1. AbletonOSC に改造を当てます。元のファイルは `.bak-<日時>` に残ります
   - `clip.py`: このツールが使う 3 つの命令 (`move_playing_pos` / `scrub` / `stop_scrub`) を足す
   - `osc_server.py`: Windows で osc-router を止めた直後などに、AbletonOSC が 1 分以上問い合わせに答えなくなる問題の対策 (WSAECONNRESET を読み飛ばす)。viewWaves など他のツールにも効きます

   ```bash
   node packages/LtcSender/scripts/apply-abletonosc-patch.js
   ```

2. Ableton Live を再起動します
3. suite-launcher から起動するか、`npm run start:LtcSender` で起動し、`http://localhost:3002` を開きます

AbletonOSC を GitHub から入れ直すと改造が消えます。その時は画面に「AbletonOSC の改造がありません」と赤く出るので、1. からやり直してください。

## Live 側の準備

- Set のテンポを台帳のテンポ (既定 120) にし、グローバルクオンタイズを **None** にする
- BGM のクリップは Warp オン、クリップの BPM を Set のテンポと同じにする
- LTC 専用のトラックを作り、出力を**専用の出力** (Master 以外) にする。エフェクト・フェード・オートメーションはかけない

## 使い方

1. 「新しいショー」でショーを作り、フレームレート・テンポ・LTC トラック・BGM トラック・LTC ファイルの出力先を設定して保存する
2. 台帳にシーンを追加し、開始時刻を決める (「01:00:00 から 1 時間ずつ振る」も使える)
3. 「LTC ファイルを作る」を押す。作った直後に読み戻して、開始時刻・途切れ・長さを検査する
4. 作ったファイルを Live の LTC トラックの同じシーンにドラッグし、**Warp オン・Re-Pitch・クリップの BPM を Set のテンポと同じ**にする
5. シーンを発音すると、画面に出ている LTC の時刻が表示され、設定や同期に問題があれば画面が赤くなる

### 途中から再生・飛ばす

- 「このシーンをここから再生」: 止まっているシーンを、曲の頭から指定した秒の位置から鳴らす (曲の頭は鳴らない)
- 「±10 秒」「上の時刻へ飛ぶ」: 再生中のシーンの全クリップを同じだけ動かす
- 本番モードでは確認が 1 回出ます。リハモードでは確認なしで実行します
- 飛ばした瞬間、LTC に壊れたフレームが 1 つ出ることがあります (照明・映像の機器で扱いを確認してください)

## 監視する内容

| 表示 | 内容 |
|---|---|
| LTC が鳴っていません | BGM が鳴っているのに、同じシーンの LTC クリップが再生中でない |
| BGM と LTC の位置がずれています | 2 つの再生位置の差が 1ms (0.002 拍) を超えた |
| LTC クリップを Warp オン・Re-Pitch に | LTC クリップの設定が違う |
| LTC クリップの BPM が違う可能性 | クリップの長さがファイルの長さと合わない |
| LTC トラックがミュート / 出力が Master | LTC トラックの設定 |
| テンポ / クオンタイズ | Set の設定が台帳と違う |
