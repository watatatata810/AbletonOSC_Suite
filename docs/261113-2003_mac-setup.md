# Mac (Apple Silicon) で使う手順

Windows と同じリポジトリ・同じ `config.json` のまま Mac でも動くようにしてある。Mac 固有の違いは下の表のとおり。

| 項目 | Windows | Mac |
|---|---|---|
| 起動 | `Ableton-Launcher_win.vbs` | `Ableton-Launcher_mac.command` (Finder でダブルクリック) |
| Neutralino の実行ファイル | `bin/neutralino-win_x64.exe` | `bin/neutralino-mac_arm64` (Intel Mac は `mac_x64`。`process.arch` で自動選択) |
| 「Ableton を起動」で開くもの | `config.json` の `global.abletonPath` | `config.json` の `global.abletonPathMac` (`.app` を `open -a` で開く) |
| AbletonOSC の場所 (User Library の既定) | `~/Documents/Ableton/User Library/Remote Scripts/AbletonOSC` | `~/Music/Ableton/User Library/Remote Scripts/AbletonOSC` |
| 各パッケージの `.bat` | 使う | 使わない (ランチャーから起動する) |

## 初回の準備

1. Node.js を入れる (Windows 側は v24 LTS で動かしている)。`node -v` で確かめる
2. Ableton Live に AbletonOSC を入れ、環境設定 > Link, Tempo & MIDI > Control Surface で `AbletonOSC` を選ぶ
3. リポジトリを `git clone` して、ルートで `npm install` を実行する
4. `config.json` の `global.abletonPathMac` を、Mac に入っている Live の名前に合わせる (既定は `/Applications/Ableton Live 12 Standard.app`。Suite / Intro なら名前が違う)
5. LtcSender を使うなら、AbletonOSC に改造を当てて Live を再起動する:
   `node packages/LtcSender/scripts/apply-abletonosc-patch.js`

## 起動できない時

- **`permission denied`** (実行権限が無い): git では実行権限付きで登録してあるが、zip で持ってきた場合などは消える。ルートで
  `chmod +x Ableton-Launcher_mac.command packages/*/bin/neutralino-mac_*`
- **「開発元を検証できないため開けません」** (ブラウザでダウンロードした zip から展開した時): ルートで
  `xattr -dr com.apple.quarantine .`
  (`git clone` で取ってきた場合はこの印が付かないので不要)
- **ファイアウォールの「受け入れますか」**: DaihonTrigger などを iPad 等の別の端末から開く時に、`node` の受信を許可する

## まだ Mac で確かめていないこと

コードは Windows 上で書いてテストまで済ませたが、Mac で実際に動かしてはいない。最初に動かす時は次の点を見る。

- ランチャーのウィンドウを閉じた時に、裏の処理 (ポート 3020 の launcher-service と各パッケージ) も止まるか。止まらない場合は `packages/suite-launcher/extensions/launcher-service/extension.log` に `Could not find the Neutralino process` が出ていないかを見る
- 前回の launcher-service が残っている時に、画面に「止めて入れ替える」が出るか (`lsof` / `ps` で調べている)
- 「Ableton を起動」で Live が開くか
