# Ableton再接続時復帰ロジック強化および耐障害性向上 設計仕様書

## 1. 目的と概要
Ableton Live の突然の終了・再起動時、および一時的なネットワーク切断や送信先ポート閉塞時に発生しうるエラーに対するアプリの耐久性と復帰動作を強化します。
具体的には、以下の2つのアプローチで安全性を高めます。
1. **Ableton切断時の画面クリーンアップ**: 切断検知時にフロントエンドのトラック要素や WaveSurfer インスタンスを安全に破棄し、古い波形が残り続けるのを防ぎます。
2. **UDP一時エラーの許容（クラッシュ防止）**: 送信先ポート未起動などによる Windows UDPエラー `10054 (ECONNRESET)` 等でサーバープロセスがクラッシュするのを防ぐため、エラーハンドリングを強化します。

---

## 2. 設計詳細

### 2.1 Ableton切断時のフロントエンド画面クリーンアップ
1. **サーバー側の挙動変更 (`packages/viewWaves/server.js`)**
   - 4秒以上 Ableton からのパケットが途切れて `abletonConnected = false` になった際、WebSocket経由でクライアントに明示的にクリア要求を送ります（`ableton_status` イベントで `{ connected: false }` を通知）。

2. **フロントエンドの挙動変更 (`packages/viewWaves/public/app.js`)**
   - 切断通知（`ableton_status` の `{ connected: false }`）またはサーバー切断時（`disconnect`）に、すべてのトラック UI と WaveSurfer のインスタンスを完全にリセット（破棄）する関数 `resetAllTracksUI()` を実行します。
   - `resetAllTracksUI()` の処理内容：
     - `tracks` オブジェクト内の各トラックについて、`wavesurferA.destroy()` および `wavesurferB.destroy()` を実行してリソースを完全に解放します。
     - トラックを包含する DOM 要素（`.track-box`）を DOM から削除します。
     - トラックキャッシュオブジェクト `tracks` を初期化します。
     - 初期空表示（`empty-state-message`）を再表示します。

### 2.2 UDP一時エラーの許容（クラッシュ防止）
1. **グローバルエラーハンドラの修正 (`packages/viewWaves/server.js`)**
   - `process.on('uncaughtException')` にて、一時的なネットワーク接続性エラー（`ECONNRESET`、`ENETUNREACH`、`EADDRNOTAVAIL`、`EHOSTUNREACH` 等）を検知した場合は、プロセスを終了せずにログに警告を記録して継続します。

2. **OSCクライアント＆サーバーオブジェクトへの個別エラーハンドラ追加**
   - `node-osc` の `Client` および `Server` インスタンスに対して個別で `error` リスナーを登録します。
   - ソケットレベルで発生したネットワーク警告を安全にキャッチして無視（ロギングのみ）することで、エラーが未処理の例外になってプロセスがクラッシュするのを根本から防止します。

---

## 3. 影響範囲とリスク
- **フロントエンドの初期化**: `wavesurfer.destroy()` を明示的に呼ぶため、不要なイベントリスナーやタイマーのリークを防ぐことができ、ブラウザのメモリ効率が向上します。
- **一時エラーの許容**: 握りつぶす対象を `ECONNRESET` 等の特定のネットワーク系エラーコードのみに限定するため、アプリコードのバグや構文例外など「本当に落とすべき致命的なエラー」を誤って無視するリスクはありません。

---

## 4. 検証計画
1. **一時的なUDPエラーの耐久テスト**:
   - Ableton Live が起動していない状態で、波形ビューアーサーバーを起動し、バックグラウンドで `/num_tracks` 等のパケットを送り続けさせます。その状態でプロセスがクラッシュせずに稼働し続け、ログに一時エラーの警告が出力されることを検証します。
2. **切断時の画面クリーンアップテスト**:
   - Ableton Live と連携して波形が表示されている状態から、Ableton Live を終了します。
   - 4秒以内に、ブラウザの枠線がオレンジ色に変わると同時に、描画されていたすべてのトラック要素が消えて「接続待ち」の初期画面（empty-state）に自動でクリーンに戻ることを確認します。
   - 再度 Ableton Live を起動した際、自動的に新しいトラック構成で波形描画が正常に再構築されることを確認します。
